5. Summary: How to Start Building Today

Building your first AI agent doesn't require a 10,000-line framework. Begin with a single Python script that executes a basic ReAct loop: prompt an LLM to output a JSON tool call, run the function locally, and feed the result back into context.

Python Blueprint: Minimalist ReAct Agent (Zero Framework Dependencies)
import json
import re

class MinimalReActAgent:
    def __init__(self, llm_client, tools):
        self.client = llm_client
        self.tools = tools  # {"tool_name": function_reference}
        self.system_prompt = """Run a continuous Thought -> Action -> Observation loop.
Available Tools:
- search_web(query: str): Returns search summaries
- calculate(expression: str): Computes mathematical operations

Format:
Thought: Describe your rationale.
Action: tool_name({"arg": "value"})
Observation: [Tool result will be inserted here]
When the goal is met, output:
Final Answer: [Definitive answer]"""

    def run(self, user_goal: str, max_iterations: int = 5):
        history = [
            {"role": "system", "content": self.system_prompt},
            {"role": "user", "content": user_goal}
        ]
        for step in range(max_iterations):
            response = self.client.generate(history)
            if "Final Answer:" in response:
                return response.split("Final Answer:")[1].strip()

            match = re.search(r"Action:\s*(\w+)\((.*)\)", response)
            if not match:
                break
            tool_name, tool_args = match.groups()
            args_dict = json.loads(tool_args)

            observation = self.tools[tool_name](**args_dict) if tool_name in self.tools else f"Error: Tool '{tool_name}' not found."
            history.append({"role": "assistant", "content": response})
            history.append({"role": "user", "content": f"Observation: {observation}"})

        return "Task could not be resolved within max steps."

4. Legal, Taxation & Payment Setup for Indian Students

Many students avoid freelancing because they believe they need complex corporate registrations, chartered accountants, and expensive payment gateways. Here is the legal reality in India:

  • GST Registration Exemption: Under the Central Goods and Services Tax (CGST) Act, service providers with an annual aggregate turnover below ₹20 Lakhs (₹10 Lakhs in special category states) are legally exempt from mandatory GST registration. You can invoice clients using your regular Personal Permanent Account Number (PAN).
  • Receiving International Client Payments: Avoid standard bank SWIFT wire transfers (which hit you with ₹500+ bank charges plus a 3-5% currency conversion spread). Instead, use Wise or Payoneer to set up virtual US/EU receiving accounts, or integrate Razorpay International with purpose code P0802 (Software Consultancy).
  • Free MSME / Udyam Certificate: Register for free at the government portal udyamregistration.gov.in. It takes 15 minutes with your Aadhaar and PAN, giving your student freelancing official recognition as a Micro-Enterprise.
