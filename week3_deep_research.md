### B. Core Architecture: ReAct & Model Context Protocol (MCP)
- **Chatbot:** $P(T_{n+1} | T_1, \dots, T_n)$ executed once in an open loop.
- **Agent:** Iterative ReAct cycle: $Goal ightarrow Thought ightarrow Tool \ Call ightarrow Environment \ Observation ightarrow Reflection ightarrow Loop/Exit$.
- **Model Context Protocol (MCP):** Open standard by Anthropic enabling agents to discover and execute tools across local processes and remote services via standardized JSON-RPC schemas without custom API glue code.
